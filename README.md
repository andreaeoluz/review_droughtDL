# Deep Learning Approaches for Drought Forecasting, Monitoring and Impact Assessment: A Comprehensive Systematic Review

This repository contains the data and supplementary materials for the systematic review.

# 🌍 Overview

Droughts are complex and multifaceted hazards with severe socio-environmental consequences. This study systematically reviews the application of deep learning (DL) models in drought prediction and monitoring, with a particular focus on the integration of remote sensing (RS) data.

# 📁 Repository Structure

```bash
├── data/
│   ├── selection_articles.xlsx    # Article screening and inclusion/exclusion tracking
│   └── data_extraction.xlsx       # Final metadata table with detailed annotations
├── notebooks/
│   └── data_representation.ipynb  # Generates Figures 3–14, in the order of the manuscript
├── figures/                       # Final figures used in the manuscript (Figure1.pdf ... Figure14.pdf)
├── references/                    # BibTeX file with all cited literature
└── README.md                      # Repository documentation
```

Run the notebook from the repository root or from `notebooks/`; each figure is saved as `figures/FigureN.pdf`. Figure 7 needs the Natural Earth *Admin 0 – Countries* shapefile (1:10m), placed in `shapefile/` or given by the `NE_COUNTRIES_SHP` environment variable. Figures 1 and 2 are LaTeX diagrams and are not generated by the notebook.
